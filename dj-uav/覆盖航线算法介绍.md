# 覆盖航线算法介绍

## 概述

覆盖航线规划（Coverage Path Planning, CPP）是无人机测绘、植保、巡检等任务的核心技术，目标是生成一条能够完全覆盖目标区域的最优飞行路径。

---

## 常见算法分类

### 1. 除草机算法（Boustrophedon/Lawnmower Pattern）✅

**原理**：沿平行线往返扫描，类似除草机割草的方式。

**实现方式**：
- 将多边形区域投影到局部平面坐标系
- 生成一系列等间距的扫描线
- 计算扫描线与多边形边界的交点
- 按往返模式连接航点

**优点**：
- 实现简单，计算量小
- 路径可预测，易于调试
- 适用于凸多边形和简单凹多边形

**缺点**：
- 对复杂形状（多孔洞）覆盖效率不高
- 固定方向可能导致航线数量过多

**适用场景**：
- 农田植保、测绘拍摄
- 矩形或近矩形区域
- 需要稳定飞行速度的任务

**当前项目实现**：
```java
CoveragePathGenerator.generateCoveragePath(
    polygonCoords,      // 多边形边界
    fieldOfViewWidth,   // 航线间距
    startPoint,         // 起始点
    directionDegrees    // 航线方向（可选）
)
```

---

### 2. 螺旋扫描（Spiral Pattern）

**原理**：从区域中心或边界开始，沿螺旋线向内或向外扩展。

**优点**：
- 路径连续无转弯，适合固定翼无人机
- 单一入口/出口点

**缺点**：
- 不适合不规则多边形
- 内圈间距可能过小导致重复覆盖

**适用场景**：
- 圆形或椭圆形区域
- 固定翼无人机巡航
- 单点起降的任务

---

### 3. 单元分解法（Cell Decomposition）

**原理**：将复杂多边形分解为简单单元（梯形、矩形等），对每个单元独立规划。

**分类**：
- **梯形分解（Trapezoidal Decomposition）**：垂直线划分单元
- **Boustrophedon Cell Decomposition**：动态处理障碍物
- **基于栅格的分解**：将区域离散化为网格

**优点**：
- 处理凹多边形和孔洞能力强
- 支持障碍物避让

**缺点**：
- 实现复杂度高
- 单元边界处可能出现重复覆盖
- 需要额外的路径优化

**适用场景**：
- 复杂建筑群巡检
- 带障碍物的区域
- L 型、H 型等凹多边形

---

### 4. 基于图搜索的方法

**原理**：构建覆盖图，每个节点代表一个覆盖单元，使用图搜索算法（A*、Dijkstra）规划路径。

**实现步骤**：
1. 栅格化区域（网格大小 = 视野半径）
2. 构建相邻单元的连通图
3. 使用搜索算法生成完全覆盖路径

**优点**：
- 支持动态避障
- 可以结合能量、时间等多目标优化

**缺点**：
- 计算量大，实时性差
- 路径可能不够平滑
- 栅格化精度影响覆盖质量

**适用场景**：
- 动态环境中的路径规划
- 需要避障的室内飞行
- 多约束条件的任务

---

### 5. 往返式变体算法

#### 5.1 最优方向往返（Optimal Direction Boustrophedon）

**原理**：尝试多个航线方向（0°-180°），选择航线数量最少或路径最短的方案。

**优点**：
- 自动适配多边形形状
- 减少转弯次数

**缺点**：
- 计算时间是普通除草机的 N 倍（N = 采样角度数）

**实现思路**：
```java
double optimalAngle = 0;
int minLineCount = Integer.MAX_VALUE;

for (int angle = 0; angle < 180; angle += 5) {
    List<CoordinatePointReq> path = generateCoveragePath(..., angle);
    if (countLines(path) < minLineCount) {
        optimalAngle = angle;
        minLineCount = countLines(path);
    }
}
```

#### 5.2 分区往返（Zone-based Boustrophedon）

**原理**：将大区域分为多个子区域，分别规划后合并路径。

**优点**：
- 适用于超大区域
- 支持多机协同（不同无人机负责不同子区域）

---

### 6. 圆形/弧形扫描（Circular/Arc Pattern）

**原理**：沿同心圆或弧线覆盖。

**适用场景**：
- 建筑物立面检查
- 塔吊、风机叶片巡检
- 以固定点为中心的监控

**实现示例**：
```java
for (double radius = minRadius; radius <= maxRadius; radius += spacing) {
    for (double angle = 0; angle < 360; angle += angleStep) {
        double lat = centerLat + radius * cos(angle) / EARTH_RADIUS;
        double lon = centerLon + radius * sin(angle) / (EARTH_RADIUS * cos(centerLat));
        waypoints.add(new Point(lat, lon));
    }
}
```

---

### 7. 基于能量优化的路径（Energy-Optimal CPP）

**原理**：考虑转弯能耗、风速、地形等因素，使用元启发式算法优化。

**常用算法**：
- 遗传算法（Genetic Algorithm）
- 粒子群优化（PSO）
- 模拟退火（Simulated Annealing）

**优点**：
- 续航时间更长
- 适应环境因素

**缺点**：
- 计算量极大，不适合在线规划
- 需要大量环境数据（风场、地形）

---

### 8. Zamboni 模式（改进的除草机）

**原理**：在往返末端使用更短的转弯半径，减少重叠区域。

**改进点**：
- 末端圆弧转弯代替直角转弯
- 动态调整航线间距

**适用于旋翼无人机**。

---

### 9. 网格覆盖（Grid-based Coverage）

**原理**：将区域划分为规则网格（方形或六边形），访问每个网格中心点。

**适用场景**：
- 离散点采样（土壤采样、污染检测）
- 六边形网格适合等间距采样

**实现**：
```java
for (int i = 0; i < rows; i++) {
    for (int j = 0; j < cols; j++) {
        double x = i * gridSize;
        double y = j * gridSize;
        if (isInsidePolygon(x, y)) {
            waypoints.add(new Point(x, y));
        }
    }
}
```

## 当前项目实现特性

`CoveragePathGenerator` 类实现的**经典往返式除草机算法**支持：

✅ **自定义航向角**（`directionDegrees` 参数，0°-360°）  
✅ **任意多边形边界**（凸多边形、简单凹多边形）  
✅ **从指定起点开始**（自动选择最近端点）  
✅ **射线法验证点在多边形内部**（处理凹多边形）  
✅ **WGS84 ↔ 局部平面坐标转换**（等距圆柱投影）  
✅ **坐标旋转**（支持任意角度航线）

## 算法选择建议

| 区域形状 | 推荐算法 | 备选方案 |
|---------|---------|---------|
| 矩形/凸多边形 | 除草机（当前实现） | 最优方向往返 |
| L 型/凹多边形 | 单元分解法 | 除草机（需手动分区） |
| 圆形区域 | 螺旋扫描 | 圆形扫描 |
| 带孔洞/障碍物 | 单元分解 + 图搜索 | 栅格化 + A* |
| 超大区域 | 分区往返 | 多机协同 |
| 能量敏感任务 | 能量优化 CPP | 最优方向往返 |
| 固定翼无人机 | 螺旋扫描 | 最优方向往返 |
| 旋翼无人机 | 除草机/Zamboni | 任意算法 |
